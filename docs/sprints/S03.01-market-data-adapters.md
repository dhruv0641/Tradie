## 1. Sprint Objective & Context

The objective of **Sprint S03.01** is to implement the vendor-agnostic market data adapter abstraction (`DataSourceAdapter` Protocol per `subsystem-contracts.md` §1) and the historical data ingestion loader for Indian equities (NSE Equities, NIFTY 50, and BANKNIFTY).

This enables:
1. Complete decoupling of quantitative strategies and data models from specific data vendors (Yahoo Finance, Kite Connect, Upstox, TruData).
2. Automated ingestion of multi-year historical daily and intraday OHLCV datasets into the Parquet archive and TimescaleDB, fulfilling Gate G0's exit requirement with ₹0 capital at risk.

## 5. Detailed Task Specifications

### TASK-03-01-001: Implement DataSourceAdapter Protocol and Factory

#### 1. Technical Specification
Implement `src/data/adapter.py` using typing `Protocol`:
```python
from typing import Protocol, runtime_checkable
from datetime import datetime
from src.domain.market_data import OHLCVCandle, MarketDepthQuote

@runtime_checkable
class DataSourceAdapter(Protocol):
    """Formal protocol for market data providers per subsystem-contracts.md §1."""

    async def connect(self) -> None: ...
    async def disconnect(self) -> None: ...
    async def is_connected(self) -> bool: ...

    async def fetch_historical_candles(
        self,
        instrument: str,
        start_time: datetime,
        end_time: datetime,
        timeframe: str,
    ) -> list[OHLCVCandle]: ...
```
Also implement `AdapterFactory` registering and instantiating configured adapters.

### TASK-03-01-002: Implement Historical CSV / Public Data Ingestion Adapter

#### 1. Technical Specification
Implement `src/data/historical_loader.py` and CLI script `scripts/ingest_historical.py`:
- Ingests historical data from CSV files and public APIs (e.g. Yahoo Finance for daily benchmarks, NSE historical archives).
- Normalizes all timestamps to UTC ISO-8601 strings.
- Converts NSE symbols to canonical format: `NSE:RELIANCE`, `NSE:TCS`, `NSE:NIFTY50`.
- Validates data through `ParquetHistoricalStore` and persists to partitioned Parquet files.
- Command-line parameters: `--symbol`, `--start-date`, `--end-date`, `--timeframe`, `--output-store`.

## 1. Sprint Objective & Context

The objective of **Sprint S04.01** is to implement the deterministic data validation pipeline (`DataValidationPipeline` in `src/data/validator.py`). Bad vendor ticks, inverted candle bounds, negative volumes, and corrupted quotes can cause catastrophic failures in quantitative indicators and risk evaluations if not caught at the entry boundary.

This module enforces the physical reality constraints defined in DDD §7 and FRD-DATA-6/7:
1. Every candle entering the system must satisfy deterministic boundary checks.
2. Anomalous or corrupt candles must be tagged as `QUARANTINED` and quarantined from downstream feature computation and trading logic.
3. Every quarantine event must generate an immutable audit log entry detailing the exact failure condition.

## 5. Detailed Task Specifications

### TASK-04-01-001: Implement Physical Price and Volume Sanity Validator

#### 1. Technical Specification
Implement `src/data/validator.py` executing deterministic sanity rules:
- Class `DataValidationPipeline`:
  ```python
  class DataValidationPipeline:
      def validate_candle(
          self,
          current: OHLCVCandle,
          previous: OHLCVCandle | None = None
      ) -> ValidationResult: ...
  ```
- Validation Checklist:
  1. **Physical Boundary Integrity**:
     - $High \ge Low > 0$
     - $Low \le Open \le High$
     - $Low \le Close \le High$
  2. **Non-Negativity Constraint**:
     - $Volume \ge 0$
     - $Turnover \ge 0$
  3. **Extreme Single-Bar Jump Filter**:
     - If `previous` candle exists: $\left|\frac{Close_{curr} - Close_{prev}}{Close_{prev}}\right| \le 0.20$ (20% maximum single-bar move for cash equities, configurable per instrument class).
  4. **Timestamp Monotonicity**:
     - If `previous` candle exists: $Timestamp_{curr} > Timestamp_{prev}$.
- Output State:
  - If all checks pass: `ValidationResult(passed=True, status="VALIDATED")`.
  - If any check fails: `ValidationResult(passed=False, status="QUARANTINED", reason="...")`.
- Action on Quarantine:
  - Logs structured warning via `structlog` with full failing payload.
  - Updates `current.quality_state = "QUARANTINED"`.

## 1. Sprint Objective & Context

The objective of **Sprint S02.01** is to implement the canonical Pydantic v2 domain models that serve as the single, strongly-typed source of truth across both the **Trading Brain** and the **Research Brain**.

Per DDD §4 and §5, domain models must enforce:
1. **Mathematical Precision**: Use `Decimal` for all financial figures (prices, quantities, costs, commissions, P&L) to eliminate floating-point inaccuracies.
2. **Boundary Validation**: Reject negative prices, negative volumes, inverted candle bounds ($High < Low$), or non-UTC timestamps.
3. **Immutable Audit Contract**: `DecisionRecord` and `TradeEvaluation` schemas must contain all input features, agent outputs, risk check snapshots, and execution outcomes for 100% decision traceability (BRD BR-7, FRD-EVAL-1).

## 5. Detailed Task Specifications

### TASK-02-01-001: Implement Core Market Data and Feature Domain Models

#### 1. Technical Specification
Implement typed Pydantic models in `src/domain/market_data.py`:
- `OHLCVCandle`:
  - `instrument: str` (e.g. `"NSE:RELIANCE"`)
  - `timestamp: datetime` (must be timezone-aware UTC)
  - `open: Decimal`, `high: Decimal`, `low: Decimal`, `close: Decimal` ($>0$)
  - `volume: int` ($\ge 0$)
  - `turnover: Decimal` ($\ge 0$)
  - `timeframe: str` (e.g. `"1m"`, `"5m"`, `"1d"`)
  - `quality_state: Literal["VALIDATED", "QUARANTINED", "STALE"] = "VALIDATED"`
  - Validators: $Low \le Open \le High$, $Low \le Close \le High$.
- `MarketDepthQuote`: 5-level bid/ask depth prices and quantities.
- `CorporateAction`: Splits, dividends, bonus adjustments.
- `FeatureSet` in `src/domain/features.py`:
  - `feature_set_id: UUID`
  - `instrument: str`
  - `timestamp: datetime`
  - `features: dict[str, float | Decimal]`
  - `feature_version: str` (e.g. `"feat-v1.0"`)

### TASK-02-01-002: Implement Master DecisionRecord and TradeEvaluation Domain Models

#### 1. Technical Specification
Implement audit models in `src/domain/decision.py` and `src/domain/evaluation.py` per DDD §5.2 and §5.3:
- `DecisionRecord`:
  - `decision_record_id: UUID`
  - `timestamp: datetime`
  - `instrument: str`
  - `decision: Literal["BUY", "SELL", "HOLD", "NO_TRADE"]`
  - `regime: str` (trend direction, volatility state)
  - `agent_scores: dict[str, float]` (individual agent scores)
  - `aggregated_score: float`
  - `risk_result: dict[str, Any]` (passed flag, failing rule ID if any)
  - `approved_quantity: int`
  - `stop_loss_price: Decimal | None`
  - `target_price: Decimal | None`
  - `config_version: str`
  - `git_commit: str`
- `TradeEvaluation`:
  - `trade_id: UUID`
  - `entry_decision_id: UUID`
  - `exit_decision_id: UUID`
  - `gross_pnl: Decimal`, `net_pnl: Decimal`, `total_slippage: Decimal`, `statutory_costs: Decimal`
  - `variance_driver: str` (e.g. `"STRATEGY_EDGE"`, `"SLIPPAGE"`, `"MARKET_GAP"`)
  - `rule_adherence: bool`

## 1. Problem Statement & Objective
Implement Multi-Stage ValidationRunner Engine executing the mandatory 6-stage validation sequence in strict sequential order (FRD-LEARN-3, ADD §8.2, MLD §9, §10) with fail-fast halting and automatic rejection marking on failure.

---

## 2. Requirements Lineage & Technical Specifications

- **Task ID**: `TASK-21-01-001`
- **Task Name**: Implement `ValidationRunner` Executing Mandatory 6-Stage Gate Sequence
- **Description**: Implement `src/governance/validation_runner.py` executing in strict sequential order (FRD-LEARN-3, ADD §8.2):
  1. Historical Backtesting (Sharpe $\ge 1.0$, MaxDD $\le 15\%$)
  2. Out-of-Sample Testing (70/30 chronological, Sharpe $\ge 0.8$, MaxDD $\le 15\%$)
  3. Walk-Forward Testing ($WFER \ge 0.50$, BTD-12)
  4. Historical / Synthetic Stress Testing (WorstDD $< 20\%$, no kill switch breach)
  5. Robustness Parameter Perturbation ($\pm 10\%$ jitter, degradation $\le 25\%$)
  6. Sandboxed Paper Trading ($\ge 30$ trades, win rate $\ge 40\%$)
- **Purpose**: Enforce that no candidate model can be considered for production without complete empirical validation (BRD BR-6, FRD-LEARN-3).
- **Source Requirements**: FRD-LEARN-3, FRD-LEARN-8; BRD BR-6; ADD §8.2; MLD §9, §10; DDD §5.4.
- **Source Documents**: `docs/add.md`, `docs/mld.md`, `docs/ddd.md`, `docs/brd.md`.
- **Dependencies**: `TASK-07-01-002`, `TASK-07-02-001`, `TASK-07-02-002`, `TASK-20-02-001`.
- **Inputs**: Candidate `ModelVersion`, historical candles, paper trading evaluations.
- **Outputs**: `src/governance/validation_runner.py`, `src/domain/validation_record.py`.
- **Implementation Notes**: If any stage fails, halt pipeline immediately, record `overall_passed = False`, log failure reason, and mark candidate `status = "rejected"`.
- **Files/Modules Changed**:
  - `src/domain/governance.py` (added `'rejected'`, `'superseded'` statuses, `frozen=False` for lifecycle transitions)
  - `src/domain/validation_record.py` (`ValidationStageResult`, `ValidationRunRecord`, `ValidationStageType`)
  - `src/domain/__init__.py` (re-exports)
  - `src/governance/__init__.py`
  - `src/governance/validation_runner.py` (`ValidationRunnerConfig`, `ValidationRunner`)
  - `tests/unit/domain/test_validation_record.py` (immutability and UTC validation tests)
  - `tests/unit/governance/test_validation_runner.py` (16 test cases covering all 6 stages and fail-fast)
- **Acceptance Criteria**: Fails candidate immediately on first stage failure; generates `ValidationRunRecord` for every stage.
- **Testing Requirements**: Integration and unit tests executing validation sequence on passing and failing models.
- **Definition of Done**: 100% test branch coverage on `ValidationRunner` (`120/120` lines, `24/24` branches).
